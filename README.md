# object_detection



## 🧠 Object Detection App with YOLOv5 and Streamlit

This project is a **real-time object detection web app** built using **Streamlit** and **YOLOv5**. It allows users to upload an image and instantly detect multiple objects within it using a pre-trained YOLOv5 model.


### 🚀 Features

* 📷 Upload any image (`.jpg`, `.jpeg`, `.png`)
* 🤖 Detect objects using **YOLOv5s** (small version)
* 📦 View detailed detection results: labels, confidence scores, bounding boxes
* 📊 Visual chart showing object count per class
* 💾 Download the image with bounding boxes
* ✨ Simple and clean user interface using Streamlit


### 🛠️ Tech Stack

* [Python](https://www.python.org/)
* [Streamlit](https://streamlit.io/)
* [YOLOv5](https://github.com/ultralytics/yolov5)
* [PyTorch](https://pytorch.org/)
* [PIL](https://pillow.readthedocs.io/)
* [NumPy](https://numpy.org/)
* [Matplotlib](https://matplotlib.org/)


### 📥 How to Run

1. Clone the repo:

```bash
git clone https://github.com/AssemElnahas/your-repo-name.git
cd your-repo-name
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the app:

```bash
streamlit run app.py
```
